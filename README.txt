دعوة زفاف المهندس محمد والآنسة ميرنا — النسخة الكلاسيكية

التصميم: عاجي وأبيض وذهبي كلاسيكي.

الملفات الأساسية:
- index.html: صفحة الدعوة.
- style.css: التصميم والحركات.
- script.js: التفاعلات والعد التنازلي والموسيقى والتهاني.
- admin.html و admin.js: لوحة التحكم.
- الصور و song.mp3: أصول الموقع الأصلية.

مهم بخصوص التهاني:
النسخة الجديدة تستخدم نفس إعدادات Firebase ونفس مجموعة Firestore المسماة weddingMessages الموجودة في النسخة الأصلية. لذلك الرسائل المرسلة من النسخة الجديدة تظهر في نفس لوحة التحكم، ولا يتم إنشاء قاعدة بيانات منفصلة. تم الإبقاء على تسجيل دخول الإدارة وآلية حذف الرسائل كما هما.

التشغيل:
ارفع محتويات هذا المجلد إلى نفس استضافة موقعك أو استضافة منفصلة تدعم ملفات HTML و JavaScript. افتح index.html من خلال الاستضافة (وليس file://) لأن ملفات JavaScript تستخدم Firebase ES Modules. لوحة التحكم من admin.html.

ملاحظة: تاريخ الفرح والقاعة والوقت ورابط الخريطة والصور والموسيقى تم الاحتفاظ بها كما في المشروع الأصلي.
